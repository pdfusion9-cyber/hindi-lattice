# hindi-lattice

हिंदी का छोटा भाषा-मॉडल, सार्वजनिक GitHub रनर पर प्रशिक्षित।

- **डेटा**: हिंदी विकिपीडिया डंप (रनर में खुद डाउनलोड होता है)
- **मॉडल**: अक्षर-स्तरीय conv, आयाम 256
- **प्रशिक्षण**: हर जॉब 5 घंटे, चेकपॉइंट आर्टिफ़ैक्ट में सहेजा जाता है

## चलाना
Actions -> train -> Run workflow

हर जॉब पिछले चेकपॉइंट से शुरू होता है, इसलिए कुल कदम जुड़ते जाते हैं।
